# VexTab Playground

Interactive playground for [VexTab](https://github.com/aurokk/vextab) notation.

## Getting Started

### Install Dependencies

```bash
npm install
```

### Development

Run the development server:

```bash
npm start
```

Then open your browser to `http://localhost:9006`

### Build

Build for production:

```bash
npm run build
```

The output will be in the `dist/` directory.

## Features

- Interactive VexTab editor with live preview
- SVG rendering using VexFlow
- Real-time error feedback
- Example VexTab notation included

## Usage

Type or paste VexTab notation into the text area and see it rendered in real-time above the editor.
